==============================
FUNCTIONAL REQUIREMENTS
==============================

1. DATA INPUT
- Load customer behavioral data from CSV:
  - customer_id
  - login_frequency
  - session_duration
  - inactivity_days
  - transaction_count
  - churn (target variable)

- Load customer feedback data from CSV:
  - customer_id
  - feedback_text

2. DATA PREPROCESSING
- Handle missing values
- Normalize numerical features
- Clean text data:
  - lowercase
  - remove punctuation
  - remove stopwords

3. SENTIMENT ANALYSIS MODULE
- Apply NLP on feedback_text
- Generate:
  - sentiment_label (Positive / Neutral / Negative)
  - sentiment_score (numeric)
- Map sentiment score to each customer
- Store sentiment_score as a model feature

4. FEATURE FUSION
- Merge behavioral features with sentiment_score
- Create final dataset for model training

5. CHURN PREDICTION MODEL
- Use Random Forest or Logistic Regression
- Perform train-test split
- Train model using behavioral + sentiment features
- Save trained model and scaler
- Output churn probability (0–100%)
- Classify churn risk:
  - Low Risk
  - Medium Risk
  - High Risk

6. MODEL EVALUATION
- Calculate and display:
  - Accuracy
  - Precision
  - Recall
  - F1-score
